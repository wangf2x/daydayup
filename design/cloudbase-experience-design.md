# CloudBase 家庭轻体验版技术方案

版本：v3.0（设计稿）  
日期：2026-10-24  
适用范围：一个家长账号、2～3 个孩子、家庭内部体验，不面向公众公开运营。

本文是当前 CloudBase 技术方案基线。原有业务需求仍以 [详细设计 v2](./design-v2.md)、[需求与验收清单](./requirements-and-acceptance.md) 为基础；本文中的新确认覆盖与图像识别、照片保留、运行架构及费用有关的旧规则。已有的初始代码骨架和模拟测试不代表真实检测/OCR 已实现、已部署或已通过实拍样例验收。

## 1. 目标与边界

- 目标是在 12 个月体验期内尽量使用免费额度，全年付费支出目标不超过 100 元；额度不足或接近预算时提示并暂停付费 OCR/模型调用，不静默超额。
- 约 1,200 道标记题识别和约 1,200 道相似题生成仅为规划估算，不等同于厂商的 API 次数或计费单位。
- 不依赖家长手动画框。系统自动发现题号上的 √、☆/★、△，自动定位题块、识别内容和判断科目。
- 识别可信、题干完整且科目明确时自动归档；只有低置信度、识别不完整或科目不明时，才要求重拍、修正或选择科目。
- 原卷导入不读取原作答、不判断原卷对错。没有可确认标记的题目不得进行题干 OCR、云端题目识别、归档或判题。
- 家长照片和孩子题库仍须进行账号、家庭、孩子及资源权限隔离；“不公开上线”不等于可以放宽鉴权。
- 暂不使用 GPU、Kubernetes 或自建常驻 Linux 服务器。若 CloudBase 免费资源不能承载标记检测，再以实测结果决定是否使用受预算约束的容器计算。

## 2. 已确认的使用与数据规则

| 项目 | 当前规则 |
| --- | --- |
| 使用人数 | 一个家庭，2～3 个孩子；家长管理孩子档案及数据 |
| 图片输入 | 支持多张照片作为同一次导入批次；按上传/指定页序处理和关联跨页内容 |
| 标记位置 | 只有题号上、题号旁或直接叠加在题号上的手写 √、五角星、三角形属于目标标记 |
| 同题多标记 | 一道题即使同时有多个标记，也只生成一个题目和一次题目识别；标签分别保留 |
| 一页多题 | 系统分别定位每道标记题；识别和用量审计按题块及厂商实际计费量分别记录 |
| 高置信度流程 | 自动检测、裁取必要题块、调用 OCR、识别科目；题干完整且科目明确时直接归档为未掌握 |
| 需要介入的情况 | 标记定位不可靠时不调用 OCR，提示重拍；题干不完整时提示修正/补拍；科目不明时由家长选择；不静默猜测 |
| 跨页/共享材料 | 同一批次的多页自动分析页序、题块和必要上下文；无法可靠关联时暂停该题，不扩大到整页 OCR |
| 题库图文 | 保存编辑后的结构化题干、小问和必要图表；图表可保留为题目附件，尽量还原原题图文关系；不保留完整题目裁剪图作为题库内容 |
| 原图保留 | 原始整页照片在该页识别结果完成处理（题目已入库，或需家长处理的题目已确认/跳过）后保留 6 个月，到期自动删除 |
| 未完成照片 | 无标记、识别失败、低置信度或待处理照片，自上传起最多保留 30 天；期间可重试或手动删除，到期自动删除 |
| 删除范围 | 期限届满只删原始整页照片；结构化题目、标签、题库状态、挑战和成绩记录保留。题目必需的独立图表附件随题库保留，直到题目/孩子按正常删除规则删除 |
| 私人照 | 家长独立相册，不绑定孩子，不启动检测、OCR、分类或生成任务 |

半年期限按照片记录并在该页识别结果全部完成处理时开始；尚未完成处理的照片仍受上传后 30 天的最长保留期限约束。期限开始事件写入照片元数据并可审计。删除任务须幂等；任务失败要告警/重试，不能把已删除照片从迟到任务中恢复。无标记图片不创建 OCR 工作，不应为了“确认无标记”调用云端 OCR。

## 3. OCR 用量和费用计量

“符号数”“题块数”“照片数”“API 请求数”“厂商计费量”是不同指标：

1. √+△ 同时标在同一道题上，业务上是一个题块、一题，只识别一次。
2. 一张照片上三道不同题分别带标记，业务上是三道题；先检测出三个题块，再分别生成最小必要 OCR 输入。
3. 一个 OCR 请求是否可以包含多张题块图，以及最终按请求、图片、页数、像素或 Token 计费，取决于实际开通的接口和合同，须用控制台和账单验证。
4. 系统分别记录上传照片数、检测到的题块数、OCR 请求数、请求输入图像数、厂商用量/费用、生成 Token 和费用。不得把一个标记符号直接记成一次 OCR。
5. 规划中的 1,200 是年度标记题/识别工作量估算，不作为免费 OCR 次数承诺。OCR 一次性赠送额度、通用 OCR 月度免费量、混元免费 Token 和 CloudBase 续期活动，均须核对具体账号、产品、接口、有效期和可叠加规则。通用 OCR 不默认可替代试题/公式识别。
6. 预算控制分为应用侧配额与云平台侧费用告警。应用达到用户设定的年度 100 元目标/上限时暂停付费 OCR、视觉和生成调用，保留题库浏览和照片删除等基础功能。CloudBase 存储、函数、流量等平台账单不一定能被应用代码硬阻断，必须另设平台用量/账单告警；100 元目标需在真实价格和资源测试后复核，不能保证免费或保证全年不超额。
7. 类似题生成与 OCR 分开计量、可单独暂停；免费额度不可用时，不影响已识别题目归档。不得为了凑“一题一变式”而绕过预算上限或自动转用未授权的付费供应商。

## 4. CloudBase 目标架构

```text
微信小程序
  ├─ CloudBase 身份认证（家长身份）
  ├─ 受限云函数/API：家庭、孩子、照片、题目、任务、题库和挑战
  └─ 私有云存储：原始照片、必要图表附件、导出文件
         │
         ├─ 持久化任务记录 / 幂等键 / 重试与配额
         ├─ 标记检测：整页仅做版面与符号定位，不做题干 OCR
         ├─ 腾讯试题/公式 OCR 适配器：只接收已选定题块和必要图表
         └─ 混元生成适配器：按预算生成、校验并发布相似题
```

### 4.1 云服务职责

| 能力 | 首选实现 | 设计约束 |
| --- | --- | --- |
| 家长登录 | 微信小程序 CloudBase 身份认证 | 服务端从可信认证上下文取得用户 ID；不信任客户端传来的家庭/孩子 ID |
| API 与业务逻辑 | CloudBase 云函数/API | 家庭、照片、题目和状态变更统一经服务端校验；生产数据禁止小程序直接任意读写 |
| 元数据 | CloudBase 数据库，封装成 repository 接口 | 先核对免费环境支持的数据库类型、事务能力和限额；掌握迁移、挑战批改、删除需有原子性/幂等性；不把客户端 SDK 直接绑定为领域逻辑 |
| 图片与附件 | CloudBase 私有云存储 | 原图不可公开；签发访问凭据前先校验家长/孩子权限；原图与必要图表附件分别记录用途、所有者、保留期限和删除状态 |
| 异步识别 | 云函数任务 + 持久化任务/事件记录 | 不依赖小程序在线等待；任务重试幂等，供应商额度/权限错误停止重试并给出明确状态 |
| 标记检测 | 首选在隔离的 CloudBase 计算环境执行轻量 CPU 推理；云函数或容器方案以真实模型包、冷启动、内存和时延测试决定 | 若免费计算不能可靠运行，评估 CloudBase 云托管/容器的实际费用；不得未经用户同意超预算，也不得退化为整页云端 OCR |
| OCR | 腾讯试题/公式识别服务，通过后端适配器调用 | 只发送系统已确认标记题的最小题块裁图和该题必需图表；不发送整页未标记内容 |
| 相似题 | 混元 API 适配器 | 结构化输出、校验、去重和费用预留；失败或超预算时保留题目原状，不发布不合格题 |
| 周期任务 | CloudBase 定时触发/后台任务 | 先以手动补充验证库存与费用，定时任务默认关闭；启用后按 Asia/Shanghai 计划幂等执行 |

CloudBase 免费环境并不自动保证适合运行图像检测模型、保存所有附件或满足 12 个月连续可用。必须先验证具体免费环境资格、资源包规则、数据库事务、函数限制、存储、下载流量和续期规则。若 CloudBase 数据库的可用事务语义不足以保证掌握/挑战/事件一致性，应在编码前调整数据聚合和事务边界，或选用明确支持这些约束的数据库套餐；不能用“先写入成功”替代数据一致性设计。

### 4.1.1 当前接入验证边界

CloudBase 控制台已显示目标小程序授权成功。小程序当前使用 CloudBase JS SDK 的 `signInWithOpenId({ useWxCloud: true })` 执行微信身份登录；微信开发者工具模拟器和真机均已完成登录，控制台可查到绑定该小程序身份源的已激活用户。真机私有 Bucket 单图上传、下载、删除及删除后检查均已通过；测试未调用标记检测、OCR 或 AI。此前匿名存储闭环已完成，匿名登录和临时 `anon` 策略已关闭/恢复。

2026-10-25 检查时，PostgreSQL `public` Schema 尚无业务表或业务 RLS 策略。第一版权限规则确认为单家长所有：家庭创建者是唯一所有者，不提供第二家长邀请。首版 `families` / `learners` 表已建立且均为空，RLS 仅有 owner-scoped SELECT 策略；表级权限已由 [database/migrations/002_restrict_family_learner_grants.sql](../database/migrations/002_restrict_family_learner_grants.sql) 收紧为 `authenticated` 只读，`anon`/`PUBLIC` 不持有这些表的权限。控制台查询确认只有 `authenticated SELECT` 授权；事务内使用两组虚构 owner 身份验证了所有者可读、另一身份不可见，随后 `ROLLBACK` 并确认两表行数仍为 0。真实双账号/真机隔离验收仍待进行。新增 `initialize-family` 云函数源码和 `daydayup_family_api` 最小权限角色迁移草案：云函数从 CloudBase 调用上下文取得 OPENID，不接受客户端 owner 字段；事务创建唯一家庭及初始孩子记录，重复调用返回既有记录，数据库角色只读/插入且 RLS 限定 owner。角色迁移初始设为 `NOLOGIN`，尚未应用；函数尚未部署。后续需经安全的数据库用户流程设置角色凭据后再启用登录、配置云函数 `DATABASE_URL`，并实测 PG 网络可达性及 `auth.uid()` 与 OPENID 映射。控制台静态语法检查提示与 CloudBase PG 官方身份认证文档不一致，但策略执行成功，数据库策略页及权限查询已确认目标角色、RLS 和权限状态。

2026-10-25 收到用户提供的数学练习册照片，确认三个待识别区域：第29页第2题、第29页第4题第（3）问（黑色√）、第30页附加题第2题（五角星）。腾讯 OCR 官方 Node.js SDK 的 `QuestionOCR` 适配器已加入 `cloudfunctions/process-import` 并通过单元测试；适配器只接受已验证的单题裁剪图，单张逐次请求并限速，忽略答案字段。此 SDK 尚未接入可运行的处理云函数；自动标记检测、题块裁剪、照片/题目 repository 仍未实现，用户提供的图片也未上传至 CloudBase。当前无真实腾讯 OCR 请求或计费发生；仅基于会话图片视觉转录，不能记作云端 OCR 联调完成。云端接入仍需在函数环境安全配置 `TENCENTCLOUD_SECRET_ID`、`TENCENTCLOUD_SECRET_KEY`、`TENCENTCLOUD_REGION`，实现并验证安全的单题裁剪与持久化，再部署后实测。

随后根据放大的双页照片复核，红色标记确认的第29页第2题和第30页附加题第2题作为临时 smoke test 范围；用户所述第4题第（3）问未能在最新照片中定位为独立完整题目，因此不纳入付费调用。CloudBase 函数控制台显示上海 1，暂用 `ap-shanghai` 作为 OCR API 区域候选。新建的 `ocr-smoke-test` 测试函数源码最多接受这两类题块，要求显式确认潜在计费、校验唯一允许的 OpenID、仅接受环境变量中预先登记 SHA-256 的图像（`OCR_TEST_ALLOWED_CROP_SHA256`），最多 2 张图且不写数据库。

2026-10-25 已实际部署 `ocr-smoke-test` 到 CloudBase，并用系统 `tar -a -c` 重打包解决 `PowerShell Compress-Archive` 生成的 ZIP 被云端判定为 zip format error 的问题。部署过程中确认两条平台限制：CloudBase 禁止函数环境变量使用 `TENCENTCLOUD_`、`SCF_`、`QCLOUD_` 前缀，因此 OCR 凭据改名 `OCR_TENCENT_SECRET_ID` / `OCR_TENCENT_SECRET_KEY` / `OCR_TENCENT_REGION`（适配器仍保留旧名回退）；控制台“测试”面板依赖 Monaco，当前网络下加载失败，故改用小程序页面内受控调用。

2026-10-25 晚完成真正的端到端联调（微信登录 → 客户端读存储 → 云函数校验 → 腾讯试题识别），两道已确认题目均返回正确题干文字，共消耗 2 次识别额度。过程中定位并修复了四个真实问题：(1) 通过 CloudBase JS SDK 调用时函数只拿到 `TCB_CONTEXT_KEYS`/`TCB_UUID`，`wx-server-sdk` 的 `getWXContext()` 因只认 `WX_CONTEXT_KEYS` 返回空对象，改为直接读上下文环境变量，`initialize-family` 也同步修复并把 `uid` 作为 owner；(2) `cloud.downloadFile({fileID})` 在当前存储后端不可用，改为客户端用签名链接取图后传 base64；(3) 存储读取受 PostgreSQL RLS 约束，控制台上传的对象 `owner_id` 不是调用者，故临时新增只针对 `ocr-smoke-test/` 前缀的 SELECT 策略 `daydayup_validation_object_select_temp_ocr`；(4) `tcb fn deploy --dir` 不带 `node_modules`，需 `--install-dependency true`。临时函数部署后出现过的 430 异常即由此引起。

2026-10-25 完成第一版产品化纵向流程（版面 + 功能）：新增 `pages/home` 错题本首页（孩子切换、本周统计、题目卡片、空态引导、悬浮拍照按钮）、重构 `pages/import` 为「拍照/选图 → 识别题干 → 核对修改（题干/科目/孩子）→ 保存」、新增 `pages/question` 详情页（编辑、切换掌握状态、删除）。新增产品级云函数 `question-ocr`：要求已登录且非匿名，必须显式确认图片为单题，限制 3 MB，返回题干与用量。数据层用 `miniprogram/services/questions.js`、`profile.js` 作为 repository 边界，当前落本机存储（`daydayup.questions.v1`、`daydayup.profile.v1`），后续替换为 PostgreSQL 不影响页面。已在模拟器实测通过：手动录入→列表→详情→标记掌握→编辑→删除；OCR 路径因新函数尚未配置 `OCR_TENCENT_*` 环境变量而返回 `OCR_PROVIDER_NOT_CONFIGURED`（每个云函数的环境变量相互独立），需补配后再验。新增单测覆盖 `question-ocr` 与本地 repository（39 项全通过）。函数尚未部署，环境中未配置任何 OCR 密钥或图像摘要；尚无真实 API 调用。

### 4.2 数据权限与隔离

- 云函数服务端是唯一业务写入边界；客户端仅提交意图和资源 ID，服务端复核资源归属、版本和状态。
- 家庭、孩子、照片、题目、作答、挑战、导出、图表附件和任务均带家庭/孩子范围；私人照单独按家长所有者授权。
- 私有照片和导出文件不使用公开永久 URL。短期下载地址也只能在授权检查后签发。
- AI/OCR 密钥只存放在云函数/容器的受保护环境变量或云密钥配置中；不得写入小程序、日志、文档或版本控制。
- OCR 和模型调用使用字段白名单；只传完成该任务所需的裁图/题目文本，不传私人照、整份未标记试卷或无关儿童信息。
- 任务状态与作答、掌握迁移、题目归档都保存版本和幂等键；迟到任务不能覆盖家长后续修改。

## 5. 自动识别流程

1. 家长选择孩子并拍摄/选择一页或多页，系统将同次上传建立为有序导入批次；家长无需绘制题框。
2. 原图私有上传，服务端建立照片记录和检测任务。若选择私人照，则只存储，不进入后续流程。
3. 检测服务做图像方向/质量处理、版面分区、题号/题块定位和标记识别；此阶段不做题干 OCR。对整页仅运行受控检测，不请求第三方云端整页识别。
4. 将符号与题号区域关联。符号直接盖住题号时允许编号未知，使用阅读顺序和邻近题块定位，不猜编号。正文几何三角形、根式、五角星和普通批改勾不能单凭形状认作目标标记。
5. 同一题多个标记合并为一个题块并保留多标签。大题标记覆盖整道大题和小问；仅小问标记只选该小问及必要共享条件。
6. 对高置信度题块创建最小必要裁图。跨页/阅读材料仅关联该题必需的上下文；禁止把相邻未标记题干带进 OCR 输入。若边界、标记、页间关系或必要材料不确定，暂停该题，提示重拍/整理页序；不得调用 OCR 作为“试试看”。
7. 仅将确定的题块和必要图表输入腾讯 OCR，解析题干、选项、小问、公式和图表。OCR 结果不提取原卷作答、不生成原卷对错字段、不进行原卷判分。
8. 结合题干和孩子教材信息判断科目。题干完整且科目置信度达到实测接受标准时直接归档为未掌握；科目不明时要求家长选择；内容不完整时要求修正/补拍。教材章节/知识点不明不阻止题目归档，可标为待整理。
9. 该页识别结果全部完成处理后，原始整页照片保留六个月；仍未完成的照片从上传时间起最多保留三十天。原图删除不影响结构化题目、历史和必需图表附件。

置信度门槛不能先写一个未经验证的固定数字。先用独立标注样本测量漏检、误检、题块边界正确率、跨页关联、OCR 修正率和科目错误率，再确定自动归档门槛。任何无法证明只处理已标记题的路径都不得开放自动 OCR。

## 6. 题库与业务能力沿用

以下核心业务规则沿用原设计：

- 江苏小学/初中按孩子实际课程和教材配置科目；科目目录可扩展。
- 每科五个菜单：整理、举一反三、挑战赛、已掌握、所有题型；前四互斥、所有题型去重。
- 新归档照片题和生成题默认未掌握；挑战错误/部分正确/主动不会按确认规则迁移至挑战赛；纠错保留版本和补偿事件。
- 挑战按既有 6/15 题默认值和 9:1 掌握比例配置，数量/比例可改；不足先预览并确认，不静默改变配额。
- 挑战赛设置（`pages/settings`）落地时提供三个开关项：跳题开关（允许不解答直接 跳过/上一题）、三档难度滑块（易/中/难，由 `difficultyOf` 按题型与年级推导并支持显式覆盖）、题量滑块（5/10/15/20，默认 10）。抽题不足目标难度池时降级并在答题页提示，不静默改配额；成绩页单独统计未作答题数。
- Word 练习版和解析版使用题库编辑文本及必要图表附件；练习版去答案，解析版只展示获准的解答。
- 举一反三生成先保存草稿、校验题意/答案/图表/教材和重复性，合格才发布；抽题不现场生成题。
- 私人照完全不参与 AI；删除题目/孩子时依现有删除合同清理内容和关联任务，不误删家长私人相册。

全量挑战、复核、导出及周更仍是后续开发项，不因 CloudBase 初期试用而取消。应按阶段交付，不能把 CloudBase 登录/上传通了说成完整方案已实现。

## 8. 当前风险与尚待现场验证

1. 没有业务源码，须按新项目从零建立小程序和 CloudBase 后端；旧 Linux 部署步骤不适用于本方案。
2. 自动标记定位是最大技术风险。没有脱敏实拍样例前，不能承诺可自动覆盖所有学科/手写风格，也不能将 OCR 自带的整页识别能力当作标记检测器。
3. CloudBase 免费资源是否适合运行检测模型，需在免费环境实测；容器计算可能使 100 元/年目标不可达，超出时暂停并重新确认，不静默转方案。
4. OCR 赠送额度、通用 OCR 免费包和混元 Token 的产品范围、额度叠加、有效期和计费单位须以实际账号和最新控制台为准。
5. 12 个月体验连续性依赖免费环境续期政策及主动操作。应在第 4～5 个月提醒检查续期/导出备份；免费额度不是 SLA。
6. 结构化数据、图表附件和原图分别统计容量；原图 3～5 GB 估算不包含长期保留的图表附件、数据库备份、日志和导出文件。
7. 体验版/家庭自用仍须核对微信小程序成员权限、合法域名/CloudBase 调用方式、隐私保护指引和第三方图像处理告知要求。
8. 现有设计资料曾包含小程序服务密钥和上传私钥明文。视为已暴露；须在对应控制台撤销/轮换。新密钥只在云端安全配置中录入，不在聊天或文档中传递。

## 9. 费用与停机行为

- 对外给用户显示本月和本年识别/生成用量，以及可核实的厂商费用；“题目数”与厂商“计费数”分列。
- 每个厂商 API 调用前检查预算预留和额度，调用后按真实用量结算；失败释放预留，重复任务使用幂等键。
- 达到预算上限、免费额度耗尽、授权失效或供应商限流时，暂停相应任务并保留可重试状态；不自动换到付费 OCR、其他 AI、整页识别或人工判错。
- 到期/超额时，用户仍可查看已归档题库、编辑已有题目、删除照片和导出已具备的数据；依赖模型的新增识别/生成明确提示不可用。
- CloudBase 平台账单与 OCR/模型账单分开监控。必须在控制台配置可用的消费提醒，并了解平台是否支持硬性消费上限；若不支持，100 元只能作为目标和应用侧暂停阈值，不是平台账单绝对封顶承诺。
