Q05—Q11 已确认：生成入库及周更新、部分正确/不会迁移、缺额确认补足、误判条件恢复、家长私人相册、可选手写拍照、大题计数及整题迁移。本清单已同步更新；成绩公式、人工复核流程和生成库存等剩余事项见设计复查记录，不把建议当作用户已确认。

- 已成功通过指定 SSH 连接服务器，未读取密钥内容，无需用户再提供密码。

| M05 | 批量切换、重试、并发修改 | 仅更新显式所选题；幂等请求无重复事件；任一越权、删除或版本冲突整批不变 |
| M06 | OCR 重试、重复归档、内容修正 | 不重置已有掌握状态，不覆盖家长操作 |
| M07 | 按默认或自定义比例挑战 | 两类题源按本场 U/M 配额抽取，不能默认排除所有已掌握或静默补题 |
| M08 | ready 前后更改状态 | ready 前重新校验配额，ready 后保留本场题数与快照；后续状态不删题 |
| M09 | 挑战答错、部分正确或主动选不会 | 自动未掌握并迁挑战赛；包括举一反三和已掌握来源，保留原题来源，不扩散同类题 |
| M10 | 挑战答对 | 记录本次成绩，不自动设为已掌握，也不改变归档资格 |
| M11 | 五菜单导出 Word | 各菜单范围独立，所有题型去重；菜单迁移或掌握变化使旧服务端导出失效 |
| M12 | 改科目、修正内容或删除 | 科目变更携带状态；内容修正不按原卷对错退出归档；删除失效关联任务与导出 |
| M13 | 查看统计 | 总数及掌握数一致，多标签不重复；原卷无错误率，挑战错误按有效事件单独统计 |
| M14 | 用户在提交挑战后改状态，批改迟到 | 新人工操作保留，错误事件记录并提示处理冲突，不用旧任务静默覆盖；跨家庭读写拒绝 |
## 五 全学科验收
全学科覆盖需要课程配置、教材映射、识别复核、题型评价和实际样例共同证明，不能只检查下拉列表。
导入阶段仅验收题目内容、范围、科目与归档，不评价原卷作答。下列样例中涉及语义等价、评分细则或表现评价的检查仅用于参考解析和挑战批改。
| 领域 | 样例和重点 |
| --- | --- |
| 语文 | 字词、阅读、表达、手写、材料引用与开放答案 |
| 数学 | 分数、根式、单位、图形；正文 √ 与题号标记区分 |
| 外语 | 英语及实际其他语种，中外文混排和语义等价 |
| 科学 | 实验图、现象、解释与条件不足处理 |
| 物理 | 公式、单位、图示和过程评分 |
| 化学 | 化学式、方程式、实验和特殊符号 |
| 生物学 | 结构图、名词和图文对应 |
| 道德与法治 | 材料、论述、要点和合理不同表述 |
| 历史 | 事件、时间、同名歧义和材料证据 |
| 地理 | 地图、图例、图表与空间关系 |
| 体育与健康 | 纸面知识；无动作证据时不猜判动作 |
| 音乐、美术及艺术子科 | 乐理、鉴赏、图示和开放作品评价 |
| 信息科技 | 算法、流程图、操作和代码题，用户内容不得当执行指令 |
| 劳动和综合实践 | 操作方案、研究材料和评分细则 |
| 地方、校本及人工智能通识 | 可配置课程和教材，不丢进无法筛选的其他类别 |
开设年级和教材以孩子实际课表为准；此表不是江苏每个年级的法定课表。每个实际开设学科均需有样例记录，不能以数学结果证明其他学科准确率。
## 六 挑战配置、批改与错误归档验收

| C20 | 批改与手动状态并发 | 遵守状态版本保护，迟到结果不覆盖提交后较新的人工决定，显示冲突提示 |

| C22 | 大综合中数学、语文等不同题型答错 | 每题回到自身科目及题型的挑战赛分组，同场可跨目录追溯；不整场归同一科，也不迁移其他同类题 |
| C23 | 题型缺失或后续修正分类 | 缺失进入本科待整理题型；分类修正更新当前目录，保留场次原分类快照、题 ID 和错误历史 |

| C39 | 部分结果与复核入口 | 提交后能查看已完成题结果和待复核项，review_required 可进入复核；未全部确认不显示最终成绩；未提交仍不可获取本场私有评分数据 |
| G01 | 生成发布 | 题意、条件、图表、答案及教材通过校验才入举一反三，不合格草稿不进入题库和抽题池 |

| G03 | 每周更新与周期调整 | 后台按配置周期执行、可暂停和手动更新；不依赖手机在线，修改周期不重复旧任务 |
| G04 | 重试、重启与费用限制 | 同窗口/计划版本任务幂等，发布不重复；达到数量/费用上限暂停，记录失败和使用量 |
| G05 | 库存补充和旧题保护 | 只按缺口补充；不重置已掌握、不覆盖已发布题目或历史成绩，无来源或库存足够则跳过 |
| G06 | 来源删除或转私人照 | 旧生成任务不能发布，依赖内容按清理规则失效；重试不恢复已删除内容 |
## 七 运行与真机验收
- Worker 和容器重启后任务可恢复，不依赖旧进程内存。
- 临时错误有上限重试，权限或额度错误明确停止，不无限排队。
- 旧规则数据不能静默改成新规则的五角星语义。
- 真实 HTTPS 域名开启合法域名校验，完成登录、上传、裁图下载及全部业务流程。
- 实际体验成员扫码可用；至少一次使用手机蜂窝网络验证公网入站。
- Android 和 iPhone 按实际可用设备记录相机、相册和隐私授权差异，未测设备明确标注。
- 验证家庭/孩子隔离、私人照零模型调用和删除时的后台任务取消。
- 数据库与图片一致恢复演练通过，恢复后不复活已删除内容。
- 日志及排错材料不包含 AppSecret、API Key 或私钥。
## 八 测量与完成判定
用独立人工真值测量符号识别、题块范围、OCR/分类、归档完整性、挑战批改、配额正确性、生成题有效性和导出效果，以及耗时与费用。原卷不测对错判定，模型自报置信度不是实测准确率。
调优数据与验收数据分开，覆盖不同科目、年级、手写风格、光照和遮挡。可以先用每类符号若干样例启动评估；交付全学科前仍需补齐代表样例。准确率门槛在真实样例和用户容忍度明确后确定，不凭空承诺一个百分比。
未标记题零 OCR/云端题干处理、原卷零判题、全部新归档默认未掌握、家庭孩子隔离、私人照零识别、每场题数及掌握配额与目标配置或用户明确确认的补足方案一致、提交前不泄露挑战评分数据为硬性门槛。
截至 2026-10-23，本清单记录的完成项仅为设计和只读盘点。2026-10-24 已新增 CloudBase 代码骨架及模拟导入测试；真实云环境、标记检测、OCR、数据库、API 权限和真机业务仍未完成，不能宣称已上线。

| 编号 | 决定 | 验收要求 |

### 标记检测管线确认（2026-10-25，取代 R35 的"自动发现"实现方式）

- 视觉模型输出契约：`[{ questionNo, marks: ['check'|'star'|'triangle'], confidence }]`，只含题序与标记类型，不含坐标、不含对错。
- 坐标与题目文本唯一来源为 `QuestionSplitOCR`（`Coord` 多边形取外接矩形并按页宽高等比归一化），其 `Subject` 作为科目初值、`KnowledgePoints` 作为知识点候选、`RightAnswer`/`Parse` 作为参考解析；`AnswerElement.IsCorrect` 丢弃。
- 标记预览仍为强制人工环节：可补标、取消误检、拖动题块边界；未确认的题不裁剪、不 OCR。
- 视觉与切题结果题数不一致、或题序置信度低时，进入"整页手动勾选"兜底，不猜测对应关系。

### 客户端实现口径（2026-10-25 落地）

- **单页调用次数修正 R45**：整页视觉调用改为「逐题裁剪一次」，即每页 1 次 `QuestionSplitOCR` + N 次单题视觉判断（N = 该页切出的题数，上限 12）。原因：实测整页模式对 √/☆ 之外符号分辨不足，而把「题号带」放大后单题判断准确率显著提升（`check`/`star`/`triangle`/`circle` 四类各 1 例全部判对）。成本换来的是准确率，家庭 2~3 人规模可接受。
- **裁剪口径**：`computeQuestionBand` 只取题目 rect 顶部一条横带（最小 90px、最大 170px，左右各留 8px），放大 2.5 倍，输出上限 900×400，避免图片 token 随原图尺寸膨胀。
- **模型分工**：单题模式默认 `hunyuan-t1-vision-20250916`（约 5 秒/题，能认出三角与圆圈），整页模式默认 `hy-vision-2.0-instruct`（约 2 秒/页，避免撞 15 秒调用窗口）。可用 `TOKENHUB_MODEL_SINGLE` / `TOKENHUB_MODEL` 覆盖。
- **切题粒度兜底**：`QuestionSplitOCR` 按版面分组，题间距过小的页面可能整页被并成 1 道高矩形；此时前端明确提示"可能漏掉其他题号"，要求重拍或分两次拍，不做猜测性切分。
- **未标记题零识别、零入库**：预览页只默认勾选识别到标记的题；用户可点标记在 `√ → ☆ → △ → 无` 间循环修正，也可手动勾选/取消。保存时只写入选中的行。



### CloudBase 首轮新增验收

- CloudBase 登录上下文能映射到家长；所有读写/下载均在服务端验证家庭、孩子和照片归属，客户端不能直接绕过授权。
- 一页含多个标记题时分别输出题块；同题多标记去重；无标记页绝不调用云端 OCR/模型。
- 标记低置信度、题块边界不清、跨页关联不清时无 OCR 请求；完整且科目明确时自动归档并默认未掌握。
- OCR 调用记录只包含标记题裁图及该题必要上下文，不含相邻未标记题干；私人照没有检测/OCR/生成任务。
- 原图在该页所有识别结果完成处理后保留六个月；待处理原图自上传起最多三十天；任务重试不复活已删资源；删除原图后题库文字和必要图表附件仍可访问。
- 预算及免费额度错误明确显示，停止相应付费工作；不得把通用 OCR 免费包默认为试题 OCR 的可替代额度。
