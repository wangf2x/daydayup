# 微信小程序配置记录（不含凭据）

本文件不保存 AppSecret、代码上传密钥、私钥或 API Key。旧版配置说明曾包含敏感凭据，已移除；相关凭据应视为已暴露并在微信公众平台撤销或轮换。

## 安全配置原则

- AppID 仅在受控开发配置中使用；部署前由管理员在微信公众平台确认当前小程序及成员权限。
- AppSecret、代码上传密钥和模型 API Key 不发送到聊天、不写入设计文档、不提交版本控制。
- 后端凭据只通过 CloudBase 环境变量/密钥配置注入；小程序客户端不包含服务端密钥。
- 更换密钥后在微信开发者工具/云端安全配置中更新，并确认旧凭据已失效。
- 体验成员、隐私保护指引、云环境授权和上传/下载权限按微信后台当前状态核验。

## 后续实施前检查

1. 管理员轮换旧 AppSecret 和代码上传密钥。
2. CloudBase 控制台创建开发/体验环境并记录非敏感环境 ID。
3. 为实际开发者和体验家长设置最小必要权限。
4. 使用脱敏试卷样例测试标记检测；不要通过聊天传递密钥或含儿童个人信息的照片。
5. 依据 [CloudBase 家庭轻体验版方案](cloudbase-experience-design.md) 配置存储保留、模型预算和隐私说明。
