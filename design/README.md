# Daydayup 需求与设计归档
归档日期：2026-10-24（Asia/Shanghai）。业务规则基线 v2.10；当前技术方案以 [CloudBase 家庭轻体验版方案](cloudbase-experience-design.md) 为准。CloudBase 方案取代旧 Linux 单机部署、人工框选和相应照片保留说明。项目已建立小程序/云函数骨架和可离线测试的导入流程，但尚无真实检测、OCR、数据库和生产业务集成。
原卷只识别标记题，全部新归档题默认未掌握；大题标记包含小问；挑战从题库抽取，单科/大综合默认 6/15 题且可调，掌握比例默认 9:1 且可调；提交自动批改，答错归未掌握及“挑战赛”。design 为当前需求依据，docs 和旧备份保留历史版本。
阅读时以本目录最新需求、验收清单和 CloudBase 方案为准；原始需求仅供追溯，其中旧标记含义已被替代。后续需求在本目录维护，并同步更新校验清单。文档所述功能尚待开发；服务器盘点材料不在当前工作区，不能作为本次实现或部署依据。
最新确认已落实：生成题归“举一反三”，默认每周更新且可调整；部分正确及主动不会均迁入挑战赛；题源缺额经用户确认后跨掌握池补足。大题计 1 题并按整题迁移；误判纠正且无后续操作/其他有效错误时恢复迁移前状态；私人照归家长独立相册。剩余评分、生成库存和交付验证事项见复查记录。
业务规则方案日期：2026-10-23；CloudBase 技术方案和初始代码骨架日期：2026-10-24。自动检测、真实 OCR、云端持久化、挑战/导出和真机部署仍待实现。
本次设计以家长管理多个孩子为使用方式，覆盖江苏小学和初中全部学科。题号上或叠加在题号上的 √ 表示题型不熟悉，五角星表示完全不会，三角形表示做题粗心。只识别带上述标记的题，未标记题不转写、不判题、不归档、不进入挑战。
拍照首次默认“错题整理”，主动切换私人照或错题整理后记住上次模式。私人照仅保存到家长独立相册，不绑定孩子、不进行任何识别；学习照必须选择孩子。标记题自动判断科目，明确时直接进入下一步，不明确时弹出科目选择；学科判断也遵守仅处理已选标记题的范围限制。
导入题按孩子与科目归档，支持科目下错题集查看、标签和知识点筛选，以及勾选题目或全部筛选结果导出 Word（.docx）。导出提供留空作答的练习版和含参考答案的解析版，仍属于待实现的第二版功能。
“整理、已掌握、所有题型”页面增加 √、☆、△ 筛选按钮：默认全灰表示包含全部，点击变白取消该标签的选择，再次点击恢复。多标签按用户最新修正：仍命中任一灰色标签就显示，例如 √ 白、☆ 灰时 √+☆ 题仍显示；只有该题全部标签都被取消才隐藏，无标签题沿用保留规则。筛选与当前列表、数量及 Word 导出一致，不改变归档和掌握状态。
每科五菜单并列：整理、举一反三、挑战赛、已掌握、所有题型。照片题归整理，模型生成且校验通过的题归举一反三，首次入库都未掌握；挑战答错、部分正确、主动不会均迁挑战赛；主动掌握后迁已掌握。前四菜单互斥，所有题型去重汇总；大综合按原科目迁移，保留题型和场次。
未掌握抽题池为整理、举一反三与挑战赛的去重并集，已掌握池为已掌握菜单。缺额确认只作用于本场，不改长期比例。五菜单均可筛选和导出。每周题库更新增量补充，周期、数量与费用受配置控制；当前尚未部署或启动定时任务。
